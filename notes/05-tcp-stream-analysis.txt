==============================================
TCP STREAM RECONSTRUCTION
==============================================

Investigation ID: TCP-005

Date: 29 September, 2026

Tool: Wireshark 4.6.6

OS: Kali Linux

Capture: 03-http-analysis.pcapng

-------------------------------------------------
1. OBJECTIVE
-------------------------------------------------

The objective of this investigation was to reconstruct an HTTP conversation
from captured TCP packets using Wireshark's Follow TCP Stream functionality.
(Right Click on a Packet Then CLick "Follow" -> "TCP Stream)

--------------------------------------------------
2. COMMUNICATION
--------------------------------------------------

Client / Source IP: 192.168.153.129

Server / Destination IP: 172.66.147.243

Application Protocol: HTTP

Destination Port: 80

HTTP Request: HEAD /

Requested Host: example.com

HTTP Response: HTTP/1.1 200 OK

--------------------------------------------------
3. ANALYSIS
--------------------------------------------------

The TCP stream was reconstructed from the captured packets to view the HTTP
communication as a complete conversation.

The client sent an HTTP HEAD request for the root resource of example.com.
The remote server responded with an HTTP/1.1 200 OK response.

The reconstructed stream allowed the request and response information to be
reviewed together rather than analyzing each packet individually.

--------------------------------------------------
4. SECURITY OBSERVATION
--------------------------------------------------

The communication used HTTP over TCP port 80.

Because HTTP is not encrypted, application-layer request and response
information can be visible to a packet analyzer when the traffic is captured.

In contrast, HTTPS normally encrypts the application-layer content.

6. CONCLUSION
----------------------------------------------------

The TCP stream reconstruction successfully demonstrated how individual packets
can be followed and reconstructed into a complete application-layer conversation.

This technique can help analysts investigate network communications without
manually interpreting every packet individually.
